# K-Means Clustering

## Overview

This project demonstrates the implementation of **K-Means Clustering**, one of the most widely used unsupervised machine learning algorithms for partitioning data into distinct groups.

The algorithm groups data points based on their similarity to cluster centroids.

## Key Features

- Centroid-based clustering
- Fast and scalable
- Easy to interpret
- Suitable for large datasets

## Algorithm

K-Means iteratively assigns data points to the nearest centroid and updates cluster centers until convergence.

## Results

The model successfully partitioned the dataset into meaningful clusters and visualized the cluster boundaries.
