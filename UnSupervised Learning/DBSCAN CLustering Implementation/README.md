# DBSCAN Clustering

## Overview

This project demonstrates the implementation of the **DBSCAN (Density-Based Spatial Clustering of Applications with Noise)** algorithm on a non-linear dataset. Unlike centroid-based clustering methods, DBSCAN identifies clusters based on data density and can effectively detect outliers.

## Key Features

- Density-based clustering
- Automatic outlier detection
- No need to specify the number of clusters beforehand
- Effective on non-linear datasets

## Algorithm

DBSCAN groups together closely packed points while marking points in low-density regions as noise.

## Results

The model successfully identified clusters in a circular dataset and demonstrated the effectiveness of density-based clustering for non-linear data patterns.
