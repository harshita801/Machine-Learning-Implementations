# Hierarchical Clustering

## Overview

This project implements **Hierarchical Clustering**, an unsupervised learning technique that builds a hierarchy of clusters based on similarity between data points.

The algorithm produces a dendrogram that helps determine the optimal number of clusters.

## Key Features

- Agglomerative clustering approach
- Dendrogram visualization
- No requirement for predefined cluster centers
- Suitable for exploratory data analysis

## Algorithm

Hierarchical Clustering starts by treating each data point as an individual cluster and progressively merges the closest clusters until a complete hierarchy is formed.

## Results

The model successfully grouped similar observations and visualized cluster relationships using a dendrogram.
