# Forest Fire Prediction using Random Forest Regression

## Overview

This project implements **Random Forest Regression** to predict the area affected by forest fires based on environmental and meteorological factors. Random Forest is an ensemble learning algorithm that combines multiple decision trees to improve prediction accuracy and reduce overfitting.

The project demonstrates data preprocessing, model training, prediction, and performance evaluation using Scikit-Learn.

## Key Features

- Implementation of Random Forest Regression
- Data preprocessing and feature preparation
- Training and testing using Scikit-Learn
- Prediction of forest fire impact
- Model evaluation using regression metrics
- Analysis of feature influence on predictions

## Algorithm

Random Forest is an ensemble learning technique that constructs multiple decision trees and combines their predictions to produce a more robust and accurate result.

### Advantages

- Handles non-linear relationships effectively
- Reduces overfitting compared to a single decision tree
- Works well with large datasets
- Provides feature importance insights

## Results

The model successfully learned patterns from environmental variables and generated predictions for the target variable. Performance was evaluated using standard regression metrics to assess prediction quality.
