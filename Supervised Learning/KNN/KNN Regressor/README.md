# K-Nearest Neighbors (KNN) Regression

## Overview

This project implements the **K-Nearest Neighbors (KNN) Regressor**, a supervised machine learning algorithm used for predicting continuous numerical values. The model estimates outputs by averaging the values of the nearest neighboring data points.

The project demonstrates data preprocessing, model training, prediction, and evaluation using Scikit-Learn.

## Key Features

- Implementation of KNN Regression using Scikit-Learn
- Data preprocessing and train-test splitting
- Prediction of continuous target values
- Regression model evaluation
- End-to-end machine learning workflow

## Algorithm

KNN Regression predicts the output value of a new observation by considering the target values of its nearest neighbors.

**Key Parameter:**
- **K (Number of Neighbors):** Controls how many neighboring samples influence the prediction.

## Results

The model successfully captured relationships between input features and target values, demonstrating the effectiveness of instance-based learning for regression tasks.
